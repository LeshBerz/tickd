## Изображения

1440×900, планшет 1280×820, телефон 390×844 CSS-пикселей при масштабе 2×. Они используются
в [README](../README.md) и [руководстве пользователя](user-guide.md). При заметном
изменении интерфейса изображения стоит переснять — как это сделать, описано
в [инструкции для разработчика](development.md#полезные-детали).
