# Роадмап Tickd

Краткий план развития продукта. Статусы: **готово** / **дальше** / **по остатку времени**.

Решения по архитектуре — в [`docs/adr/`](adr/). Визуальный ориентир UI — [`design/prototype.html`](../design/prototype.html).

## Готово

- Статический UI-прототип и перенос ядра в React.
- Каркас: Vite, TypeScript, Redux Toolkit, React Router, Tailwind CSS v4, Biome, Vitest, Playwright.
- Домен задач: добавление, переключение, удаление; фильтр как маршрут (`/`, `/active`, `/completed`); persistence в `localStorage` со схемой Valibot и миграцией v0 → v1.
- Ядро UI по прототипу (тег `v1-core`).
- Ограничения и защита ввода: лимит заголовка, нормализация вставки, баннеры сбоев/`quota`/повреждённых данных, CSP, запрет `dangerouslySetInnerHTML` ([ADR 0007](adr/0007-input-validation-and-security.md)).
- Счётчик активных задач («N items left») и «Clear completed».

## Дальше (в этом порядке)

1. **Редактирование** — по двойному клику; Enter сохранить, Esc отменить; пустой заголовок не сохраняется.
2. **Отмена удаления** — toast с Undo (`role="status"`, авто-скрытие).
3. **Горячие клавиши** — фокус в поле ввода (`/` / `n`), переключение фильтров (`1` / `2` / `3`) вне полей ввода. Подсказки `<kbd>` только при `@media (hover: hover) and (pointer: fine)`.
4. **Карточка задачи с заметками** — маршрут `/<filter>/tasks/:id`, поле `notes` с лимитом, схема хранения v2 и миграция v1 → v2.
5. **Настройки** (`/settings`) — тема system / light / dark, акцентный цвет (палитры с проверкой контраста AA), язык ru/en через библиотеку i18n, переключатель подсказок клавиш. Отдельный версионируемый ключ preferences.
6. **Гид** — 4–5 шагов при первом визите и повторный запуск из настроек; в пустом состоянии — «загрузить пример задач».

## По остатку времени

- Синхронизация вкладок (`storage` event, last-write-wins).
- Перетаскивание (dnd-kit; только на фильтре «Все», с клавиатурной альтернативой).
- Анимации (Motion, учёт `prefers-reduced-motion`).
- PWA (офлайн).
- Модуль Lists / projects (отдельная миграция схемы хранения).

## Принципы

- Одно логическое изменение — один коммит; каждый коммит сам проходит lint, typecheck, unit и e2e.
- Новые runtime-зависимости только после явного выбора и проверки актуальной версии.
- Фильтр остаётся маршрутом, а не локальным state ([ADR 0001](adr/0001-filter-as-route.md)).
