# Роадмап Tickd

Краткий план развития продукта. Статусы: **готово** / **дальше** / **по остатку времени**.

Решения по архитектуре — в [`docs/adr/`](adr/). Визуальный ориентир UI — [`design/prototype.html`](../design/prototype.html).

## Готово

- Статический UI-прототип и перенос ядра в React.
- Каркас: Vite, TypeScript, Redux Toolkit, React Router, Tailwind CSS v4, Biome, Vitest, Playwright.
- Домен задач: добавление, переключение, удаление; фильтр как маршрут (`/`, `/active`, `/completed`); persistence в `localStorage` со схемой Valibot и миграцией v0 → v1.
- Ядро UI по прототипу (тег `v1-core`).
- Ограничения и защита ввода: лимит заголовка, нормализация вставки, баннеры сбоев/`quota`/повреждённых данных, CSP, запрет `dangerouslySetInnerHTML` ([ADR 0007](adr/0007-input-validation-and-security.md)).
- Счётчик активных задач с локализованными формами множественного числа и очистка выполненных.
- Редактирование заголовка по двойному клику / Enter; Esc отменить; пустой заголовок не сохраняется.
- Отмена удаления: toast Undo (`role="status"`, авто-скрытие) ([ADR 0008](adr/0008-undo-snapshot-for-deleted-tasks.md)), центрируется по видимой области задач (колонка списка при открытой карточке, иначе по `main`, на мобильном — по вьюпорту над футером).
- Горячие клавиши: фокус в поле ввода (`/` / `n`), переключение фильтров (`1` / `2` / `3`), отмена удаления (`z`) вне полей ввода. Подсказки `<kbd>` только при `@media (hover: hover) and (pointer: fine)` и включаются переключателем в настройках (`selectShowKeyboardHints`); подсказка `N` и кнопка добавления собраны в один правый блок, поэтому не пересекаются ни в одном языке.
- Карточка задачи с заметками: маршрут `/<filter>/tasks/:id`, панель деталей справа (на мобильном — на всю ширину), клик по заголовку открывает карточку, поле `notes` с лимитом 2000, схема хранения v2 и миграция v0/v1 → v2. Поле заметок растёт вместе с текстом до предела (420 px), дальше прокручивается внутри, под полем остаётся только счётчик. На широком экране колонка списка не сдвигается и не меняет ширину при открытии карточки — свободное место справа забирает панель деталей.
- Настройки (`/settings`): тема system / light / dark без вспышки при загрузке, акцентные палитры с проверкой контраста AA, язык ru/en (i18next), переключатель подсказок клавиш. Отдельный версионируемый ключ `tickd:preferences` (версия 2, миграция v1 → v2 сохраняет тему, язык, акцент и подсказки).
- Гид первого визита: 5 шагов с подсветкой цели, Next / Back / Skip, закрытие по Escape, focus trap и возврат фокуса; повторный запуск из `/settings`; флаг `guideCompleted` хранится в `tickd:preferences`, а не в задачах. В пустом состоянии — «Загрузить примеры задач» (три локализованные задачи с фиксированными id, повторный запуск не создаёт дубликатов).
- Фирменный знак: логотип-галочка в шапке и сайдбаре, favicon; короткие анимации появления (список, панель деталей, toast, карточка гида) на CSS с отключением по `prefers-reduced-motion`.

## По остатку времени

- Синхронизация вкладок (`storage` event, last-write-wins).
- Перетаскивание (dnd-kit; только на фильтре «Все», с клавиатурной альтернативой).
- Более выразительные анимации (Motion, учёт `prefers-reduced-motion`).
- PWA (офлайн).
- Модуль Lists / projects (отдельная миграция схемы хранения).

## Принципы

- Одно логическое изменение — один коммит; каждый коммит сам проходит lint, typecheck, unit и e2e.
- Новые runtime-зависимости только после явного выбора и проверки актуальной версии.
- Фильтр остаётся маршрутом, а не локальным state ([ADR 0001](adr/0001-filter-as-route.md)).
